# 场景驱动战略投资研究与领导汇报



> 一个面向战略投资、产业投资与企业战略部门的可复用 Agent Skill。它从被研究企业的真实能力边界出发，将客户场景、生态责任、完整产业链、具体产品卡位、总拥有成本、商业模式与阶段性资本工具连成一条可审计的决策链，并输出可编辑的领导汇报材料。
> 


## 解决什么问题



许多战略投资研究停留在“赛道很热、市场很大、技术很先进”的层面，或者把场景、生态、技术、投资建议堆成互不相连的清单。本技能要求从企业实际能进入、能交付、能承担责任的系统接口出发，先回答客户问题，再定位产业链责任断点，最后收敛到**具体产品、算法、材料、设备、软件或公司类型**。



它不预设某项技术、某种商业模式或某个投资对象就是答案。用户给出的技术、案例或跨行业类比均被视为待验证假设，必须与主流、替代和前沿路线进行比较，并接受成本、工程化、供应、客户切换和责任边界的反证。



## 唯一决策链



```text

企业能力与经营边界

→ 全场景

→ 全生态/责任链

→ 场景 × 生态问题

→ 完整产业链

→ 具体产品/算法/公司类型

→ 总拥有成本与价值捕获

→ 项目导入

→ 阶段与交易闸门

→ 领导授权/停止条件

```



其中，**场景用于发现客户结果，生态用于定位系统责任短板，具体产品才是布局对象，阶段与交易闸门才形成战略投资结论**。这四层不能混用。



## 核心方法



| 模块 | 要求 | 产出 |

|---|---|---|

| 企业事实卡 | 明确企业已有产品、项目入口、区域、经营约束与不做边界 | 不把企业误写成另一类公司 |

| 全场景与生态图 | 全量识别场景和责任链，只标记初步下钻方向 | 客户问题与系统责任短板 |

| 完整产业链深钻 | 展示上游—中游—下游及数据、认证、服务、循环环节 | 可审计的价值与责任交接点 |

| 技术路线判断 | 比较主流、候选、前沿和替代路线 | 适配场景、工程/良率、成本曲线、可靠性、供应与TCO结论 |

| 战略卡位 | 只保留产品级投资节点，比较自建、采购、合作、投资、并购 | 具体产品、公司类型、企业接口与不做边界 |

| 价值捕获 | 从价值池反推付费方、收费单元、现金流归属及市场边界 | 不同商业模式下的市场空间与估值语言 |

| 阶段决策 | 按技术、工程、成本、法规、项目和商业化窗口设置动作 | 观察、联合验证、小额期权、少数股权、增持或退出 |



## 一级市场与早期技术项目



早期项目**不能按成熟公司标准机械筛选**。没有规模订单、收入、利润、全套认证或量产能力不构成自动否决；但也不能只凭概念、实验室样品或远期市场图进入候选池。



技能将证据按阶段适配：原理/种子期看技术机理、核心团队、关键知识产权、可证伪实验与成本假设；工程样机期看可重复性、关键失效模式、物料清单与工艺路径；中试/早期商业化阶段再看良率爬坡、认证路径、单位经济和初始商业化。任何阶段都必须有下一项可证伪里程碑与停止条件。



## 技术、成本与商业模式纪律



技术代际、峰值性能或“国产替代”均不自动等于投资价值。每条路线必须回答：它在什么具体场景解决什么问题，能否制造、良率如何提升、可靠性和认证路径是什么、供应链能否支撑、客户为什么愿意切换，以及系统**总拥有成本（TCO）**何时优于主流方案。



市场规模也不能只写一个总市场数字。同一项底层技术，按材料/标准件、模块设备、软件授权订阅、工程服务或交易/结果分成收费，价值池、现金流、毛利结构、营运资本和估值逻辑都不同。必须按照“价值池 → 付费方 → 收费单元 → 现金流归属 → 总市场/可服务市场/可获得收入 → 规模上限”推导。



国产替代或供应安全只在以下条件逐项成立时作为单独、可追溯的战略加分：真实受限或依赖、目标场景可用、可工程化制造、总成本可接受、客户愿意切换、自主可持续，以及合规与地缘风险可控。它不能被重复计入收入、利润、估值倍数和退出概率。

## 使用方式



将整个目录作为 Agent Skill 加载，并按 `SKILL.md` 的启动判断和强制工作流执行。以下输入越完整，结论越能落到具体投资节点：企业公开材料与内部事实卡、管理层约束、客户场景/项目问题、交付模板、区域法规、技术/供应商线索及已有尽调材料。



```text

请基于 [目标企业] 的真实能力边界，使用“场景驱动战略投资研究与领导汇报”技能，完成 [行业/区域/战略问题] 的研究。

要求：保留可编辑PPT、主Excel、双Markdown报告与导航；先全景后收敛；每个重点卡位点必须给出完整产业链、产品级投资对象、TCO、商业模式、阶段闸门和不做边界。

```

## 质量与边界



本技能要求区分监管/标准/审计与原始测试等A级事实、权威公开资料等B级信息，以及商业计划书、口头转述和营销材料等C级主张。未签约协同、未授权数据、潜在订单、管理层目标或景气判断不得直接计入收入、回报或估值。



自动审计只负责发现缺失、表述和结构风险，不能代替人工红队审查。涉及投资、法律、技术性能、市场规模或财务预测的结论，仍须根据目标企业、所在市场、参考日期与一手证据完成项目级判断。
